Unidad 1: Estructura de los Programas Contables y Tipos de Software

Funcionalidades de los ERPs, software contable On-Premise vs. Cloud SaaS y criterios de selección técnica.

On-Premise (Escritorio)

Software en Servidor Local

Ejemplos: Galac, Profit Plus, Saint, SIGESP.

Instalación local, control físico directo de bases de datos, pero requiere infraestructura y servidores propios.

Cloud SaaS (Nube)

Software Contable en Nube

Ejemplos: Alegra, QuickBooks, Xero, Odoo Cloud.

Acceso remoto 24/7 desde cualquier dispositivo, respaldos automáticos, ideal para trabajo híbrido.
